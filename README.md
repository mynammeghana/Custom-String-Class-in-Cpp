
# Custom-String-Class-in-C++
A mini project implementing a custom String class in C++ using a dynamically allocated character array, without using std::string.

Features Constructors: default, parameterized (const char*), copy constructor Operators: assignment (=), concatenation (+), subscript ([]), comparison (==, !=, <, >, <=, >=) Stream I/O: << and >> implemented as friend functions Friend string functions: strcpy, strncpy, strcmp, strncmp, strcat, strncat, strrev, strupr, strlwr, strchr, strrchr, strstr, strlen — all operating directly on String objects Deep copying, proper memory management, and a destructor to avoid leaks.
